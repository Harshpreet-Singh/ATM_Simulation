# ATM Simulation System

This project is a simple ATM simulation that demonstrates basic banking operations. It allows users to check their account balance, deposit money, withdraw funds, and view a transaction history.

## Features
- Display balance
- Deposit money
- Withdraw money
- Transaction statement

## How to Run
1. Clone the repository
2. Navigate to the project folder
3. Run the main file using your programming language

## Purpose
This project is intended for learning basic programming concepts such as control flow, functions, and data handling.
